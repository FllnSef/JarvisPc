# Jarvis PC — полноценное Windows-приложение

Проект включает нативный интерфейс на PySide6/QML, голосовое управление, системный трей, анимированного 2.5D-робота, игровой и рабочий режимы и поиск фильмов на Кинопоиске.

Робот поддерживает шесть визуальных состояний: ожидание, прослушивание, размышление, выполнение, успех и ошибка. Цвет подсветки и motion-анимация меняются вместе с реальным состоянием Python-ядра. Во время записи показывается живая волна уровня микрофона, а результаты выводятся во всплывающих карточках.

## 1. Откройте PowerShell в папке проекта

В Проводнике откройте папку `JarvisPC`, щёлкните правой кнопкой по свободному месту и выберите «Открыть в терминале».

## 2. Найдите Python

```powershell
python --version
py --version
where.exe python
```

Достаточно, чтобы сработала одна из первых двух команд. Рекомендуется Python 3.10 или 3.11.

## 3. Подготовьте окружение

Если работает команда `python`:

```powershell
.\setup.ps1
```

Если Python не добавлен в PATH, укажите его файл явно:

```powershell
.\setup.ps1 -PythonPath "C:\путь\к\python.exe"
```

Скрипт создаст `.venv` и установит `PySide6`, `keyboard`, `pyttsx3`, `sounddevice` и `vosk`.

Если PowerShell запрещает запуск локальных сценариев, разрешите их только для текущего окна:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
```

## 4. Проведите безопасный тест

```powershell
.\test.ps1
```

Тест:

- проверит девять сценариев, состояния интерфейса и наличие ассетов;
- покажет найденные и отсутствующие приложения;
- смоделирует игровой режим, ничего не открывая.

Ожидаемый итог юнит-тестов: `Ran 9 tests` и `OK`. Radmin VPN сейчас может отображаться как `MISSING` — при настройке он не был обнаружен.

## 5. Подключите русский голосовой ввод

Автоматически скачайте компактную русскую модель Vosk:

```powershell
.\download-model.ps1
```

После распаковки должен существовать каталог:

```text
models\vosk-model-small-ru-0.22
```

Без модели программа тоже запустится, но после горячей клавиши попросит ввести команду текстом.

## 6. Запустите Джарвиса

```powershell
.\start.ps1
```

Откроется отдельное приложение с тёмным интерфейсом, центральным роботом, боковой панелью режимов и строкой команд. Робот плавно появляется при старте, парит и реагирует на положение курсора. Во время прослушивания вокруг него включается пульсация.

Кнопки справа в заголовке окна:

- `⚙` — экран настроек микрофона, голоса, громкости, скорости и горячих клавиш;
- `◱` — компактный режим;
- `⛶` — полноэкранный режим;
- `⌄` — скрыть приложение в системный трей;
- `—` — обычная минимизация;
- `×` — полностью завершить приложение.

- `Ctrl+Alt+J` — начать запись команды;
- `Ctrl+Alt+Q` — завершить программу.

Прежний консольный режим сохранён:

```powershell
.\start-console.ps1
```

## Проверка микрофона и распознавания

Перед первым полноценным запуском выполните:

```powershell
.\voice-test.ps1
```

Сценарий покажет все устройства ввода, заранее загрузит модель и попросит произнести одну команду. При успешной проверке появится строка `Распознано: ...`. Приложения при этом не запускаются.

Если используется не тот микрофон, возьмите его номер из списка, например `3`, и повторите:

```powershell
.\voice-test.ps1 -Microphone 3
```

Запуск Джарвиса с выбранным микрофоном:

```powershell
.\start.ps1 -Microphone 3
```

Список системных голосов:

```powershell
.\.venv\Scripts\python.exe .\run.py --list-voices
```

Примеры:

```text
Джарвис, включи игровой режим
Джарвис, включи рабочий режим
Джарвис, открой Телеграм
Джарвис, включи фильм Интерстеллар
```

## Быстрый тест одной команды

Без открытия приложений:

```powershell
.\.venv\Scripts\python.exe .\run.py --command "рабочий режим" --dry-run --silent
```

С реальным выполнением:

```powershell
.\.venv\Scripts\python.exe .\run.py --command "открой телеграм"
```

Во втором случае Telegram действительно будет открыт.
